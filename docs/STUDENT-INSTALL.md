# 내 컴퓨터에 설치하기

처음에는 **압축 풀기 → 앱 열기 → 국내 또는 미국 종목 찾기**까지만 해보세요. 여기까지는 AI 키 없이 할 수 있습니다. 에이전트에게 질문할 때 본인의 AI 서비스를 한 곳 연결합니다.

## 1. 내 컴퓨터에 맞는 ZIP 받기

[수강생 다운로드 페이지](https://github.com/rrw9002-ops/Hyperpass-Research-Web/releases/tag/v0.7.4-preview)를 엽니다. 아래 **Assets**를 펼쳐 다음 파일 중 **하나**를 클릭하세요. GitHub 로그인은 필요 없습니다.

- **Windows 64비트**는 `Hyperpass-Research-Web-Windows.zip`을 받습니다. Windows 설정 → 시스템 → 정보에서 시스템 종류를 볼 수 있습니다. 이 배포판의 검증 대상은 x64입니다.
- **Mac**은 왼쪽 위 사과 메뉴 → 이 Mac에 관하여를 엽니다. **칩**에 Apple M1·M2·M3 등 M 시리즈가 보이면 `Hyperpass-Research-Web-macOS-arm64.zip`을 받습니다. **프로세서**에 Intel이 보이면 `Hyperpass-Research-Web-macOS-x86_64.zip`을 받습니다.
- 이름에 `source`가 들어간 ZIP은 앱 코드를 직접 바꾸는 실습용입니다. `.sha256`은 다운로드 확인용 파일입니다. 처음 실행할 때는 운영체제 이름이 들어간 ZIP을 고르세요.

## 2. 압축을 모두 풀고 실행하기

1. **Windows**에서 다운로드 폴더를 열고 받은 ZIP을 마우스 오른쪽 버튼으로 클릭한 뒤 **모두 압축 풀기**를 누릅니다. 압축이 풀린 폴더 안으로 들어가 `Start-Windows.cmd`를 두 번 클릭하세요. 확장자를 숨긴 환경에서는 `Start-Windows`로 보일 수 있습니다.
2. **Mac**에서는 Finder → 다운로드에서 ZIP을 두 번 클릭합니다. 생긴 폴더를 열고 `Start-Mac.command`를 두 번 클릭하세요.
3. 실행 창이 열리고 브라우저에 **HYPERPASS** 화면이 표시됩니다. 브라우저가 자동으로 열리지 않으면 실행 창에 나온 `http://127.0.0.1:숫자` 주소 전체를 복사해 브라우저 주소창에 붙여넣으세요. 포트 번호는 컴퓨터마다 다를 수 있습니다.
4. 위쪽에 **리서치 팀 · 차트 연구실 · 스크리너 · 백테스트**가 보이면 설치가 끝났습니다. 오른쪽 위 **수강생 가이드**로 이 문서를 다시 열 수 있습니다. 앱을 켜지 않고 읽으려면 압축을 푼 폴더의 **수강생-시작가이드.html**을 여세요.

실행 창은 사용하는 동안 열어 두세요. 마칠 때는 그 창에서 `Ctrl+C`를 누릅니다. 다음 수업에는 같은 폴더에서 같은 시작 파일을 실행하세요. Windows·Mac 실행용 ZIP에는 Python 실행 환경이 포함되어 있습니다.

## 3. 연결 없이 첫 화면 확인하기

1. **스크리너 → 국내**를 선택하고 **한국투자증권 KIS**와 수신 시각을 확인합니다. 키를 연결하기 전에는 KIS가 공개한 종목 파일의 **기준가**가 표시됩니다.
2. 검색 칸에 `005930`을 입력하고 **검색하기**를 누릅니다. **삼성전자 · 005930** 행이 보이면 종목을 찾은 것입니다.
3. 같은 행의 **차트**를 누릅니다. 인터넷 연결 상태에서 Yahoo 가격 이력이 들어오면 **삼성전자 · 005930 / 일봉**과 실제 출처·봉 개수가 표시됩니다.
4. AI 화면도 둘러보려면 **리서치 팀 → 화면 체험**을 누릅니다. 체험은 정해진 예시로 화면 사용법을 보여줍니다. 본인의 실제 보고서는 다음 장에서 AI를 연결한 뒤 만듭니다.

## 설치가 멈췄을 때

- **ZIP 안에 파일이 많은데 무엇을 누를지 모르겠어요.** 다운로드 폴더에 있는 원래 ZIP을 닫고 압축을 푼 새 폴더로 이동하세요. 윈도우는 `Start-Windows.cmd`, 맥은 `Start-Mac.command`입니다.
- **주소가 열리지 않아요.** 앱 실행 창이 열려 있는지 확인하고 그 창에 표시된 주소를 다시 사용하세요. 강사 화면의 포트 번호를 복사하면 다른 주소로 갈 수 있습니다.
- **Mac 또는 Windows가 실행자를 확인할 수 없다고 해요.** 강사가 안내한 공개 릴리스에서 운영체제에 맞는 파일을 받았는지 먼저 확인하세요. 배포본의 서명·공증 상태에 따라 경고가 표시될 수 있습니다. 회사나 학교 컴퓨터라면 표시된 경고 문구와 OS 종류를 담당자에게 전달하세요. [Apple의 Mac 앱 실행 안내](https://support.apple.com/ko-kr/102445)
- **이 창을 닫아 버렸어요.** 압축을 푼 폴더에서 시작 파일을 다시 여세요. 앱을 완전히 다시 시작하면 필요한 API 키를 다시 연결합니다.
