# TradingView 차트 연결

## 차트 연구실에서 Desktop 시세 보기

1. 내 PC에 [TradingView Desktop](https://www.tradingview.com/desktop/)을 설치합니다. Hyperpass에서 **차트 연구실 → 차트 데이터 → TradingView · Desktop 차트 조회**를 선택하세요.
2. 오른쪽에 **TradingView Desktop 연결하기**가 나타나면 **Desktop 연결 실행**을 누릅니다. 이 버튼은 설치된 Desktop을 이 컴퓨터의 로컬 연결 모드로 시작합니다. 보통 포트는 기본값 `9222`를 그대로 씁니다. 일반 모드로 켠 Desktop이 이미 열려 있어 연결에 실패하면 작업을 저장하고 앱을 완전히 종료한 뒤 다시 누르세요.
3. Desktop에서 사용할 종목 차트를 엽니다. 앱이 잠시 기다리며 연결을 다시 확인합니다. 차트가 여러 개면 Hyperpass 오른쪽의 목록에서 **실습용 탭**을 고르세요. 연결 버튼을 누른 뒤 자리를 비웠다면 **연결 확인 · 차트 조회**로 이어갑니다.
4. Hyperpass에 종목명이나 티커를 입력하면 지정한 탭이 요청한 종목·주기로 바뀌고 오른쪽에 관측된 봉이 표시됩니다. 입력란을 비운 상태에서 상단 **차트 조회**를 누르면 열린 종목을 읽습니다. 오른쪽 제목의 종목명·코드, **TradingView Desktop** 출처, 실제 봉 수를 함께 확인하세요. Desktop이 로드한 봉 중 최대 500개를 읽습니다.

**TradingView에서 열기**는 거래소가 포함된 해당 종목의 외부 웹 차트를 엽니다. Hyperpass에서 개인 지표를 그리거나 기술 분석 에이전트에게 봉을 전달할 때는 연구실에 표시된 데이터를 사용합니다. Desktop 연결이 어려운 환경에서는 **TradingView · CSV 가져오기**에 내보낸 파일을 넣거나, **이 종목을 Yahoo Finance로 조회**를 선택하세요. 오른쪽에 선택한 출처가 표시됩니다.

## 리서치 에이전트에 열린 차트 연결하기

**데이터 연결 → TradingView → chart**에서 같은 로컬 포트와 열린 차트의 정확한 `거래소:종목`을 지정하세요. 예를 들어 삼성전자는 `KRX:005930`입니다. 이 읽기 모드에서는 열린 차트의 종목이 일치해야 하며 이미 표시된 OHLCV 봉, 주기·통화, 지표 이름과 데이터 창 표시값을 가져옵니다. 차트 연구실에서 선택한 탭으로 종목을 바꾸는 동작과 별도로 사용할 수 있습니다.

오른쪽의 **KRX 지연 시세**는 TradingView가 지연 피드 `KRX_DLY`를 돌려줬다는 뜻입니다. 새로 읽은 차트는 실제 가격 시계열의 종목·주기와 봉 로딩 완료를 확인해 원본에 함께 기록합니다. 이전 버전에서 저장한 Desktop 차트를 투자 판단에 쓰려면 상단 **차트 조회**로 새로 받아 비교하세요.

포트는 `127.0.0.1`에서만 사용합니다. 차트 연결 실습을 마치면 필요에 따라 TradingView를 정상 종료하고 평소처럼 다시 열 수 있습니다.

마지막 봉은 진행 중일 수 있습니다. `as_of`는 봉 시작 시각이며 실시간 완료 시각이
아닙니다. 지표 값은 데이터 창의 표시값으로, 마우스 커서가 가리키는 봉일 수 있어
관측 봉 시각을 `data_window_selection_unknown`으로 표시합니다. 마지막 OHLCV 봉과
동일 시점이라고 가정하지 않습니다. 표시값에는 포맷·단위·반올림이 적용될 수 있습니다.

TradingView 내부 getter는 공식 외부 데이터 API가 아니므로 앱 업데이트에 따라
바뀔 수 있습니다. 표시되지 않거나 접근할 수 없는 지표는 생성하지 않습니다.
조회 실패 시 `scanner` 또는 사용자가 직접 내보낸 `csv`를 명시적으로 선택할 수
있지만, 이를 차트 연결 성공으로 표시하지 않습니다. 데이터 이용 권한은 사용자의
TradingView 계정·거래소 구독·서비스 약관을 따릅니다.
