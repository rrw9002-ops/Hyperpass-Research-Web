기존 프로세스의 유료 성공을 새 EXE의 유료 호출 검사로 표현하지 않습니다.

앞선 `gpt-5-mini` 실행에서는 잘못된 근거 ID, 중복 역할, 준비도와 연구 완료의 혼동,
얻을 수 없는 자료의 반복 요청을 관찰했습니다. 미완료·중단 기록은 성공으로 세지
않았습니다. 단위·출처 메타데이터와 인계 지침을 보완했고, 잘못된 참조·작업 형식은
기존 호출 상한 안에서 Head Manager에게 한 번만 보정 요청합니다. 추가 재실행에서
독립 검토에 넘길 후보 본문이 빈 응답도 관찰하여, 같은 채택 ID 보정 횟수 안에서
상태 적용 전에 한 번만 다시 작성하도록 처리했습니다. 재실패·예산 소진은 완료로
바꾸지 않습니다. 역할 구성과
근거 채택·독립 검토 게이트는 유지합니다. 모든 모델의 동일 성공을 보장하지 않습니다.

완료 사례의 원문 대조에서는 보고 기간 경계를 마지막 체결일처럼 표현하거나,
금액·비율 극값을 같은 거래로 묶고, 가격 갭까지 미반영으로 설명하는 표현을

투자 판단 정확성 보장을 뜻하지 않습니다. 실제 재확인 기록은 릴리스 검증 JSON에 남깁니다.

## 이전 로컬 Windows 설치 검증 — v0.4.0-preview

최신 소스에서 Python 3.14.3과 PyInstaller 6.22.3으로 Windows EXE를 다시 빌드했습니다.
소스 설치, EXE 하나만 복사한 설치, Windows ZIP을 압축 해제한 설치를 각각 한글·공백이
있는 임시 폴더에서 별도 프로세스로 실행했습니다. 세 경로 모두 같은 9개 HTTP 점검을
통과했습니다. 기존 실행 중인 앱이나 사용자 연구 데이터는 변경하지 않았습니다.

1. localhost 페이지와 작업 공간 자원 로딩, AI 미연결 초기 상태.
2. 팀 지침 33개, 편집·백업, 수정 경합 409, 경로 이탈 차단.
3. 잘못된 CSRF 토큰과 키 없는 실제 AI 실행 요청 거부.
4. 합성 OHLCV 120행의 CSV 계산·저장, JSON/Pine 내보내기.
5. 고정 기술 분석 데모의 근거 채택·독립 판단 검토·보고서 완료와 저장된 지침 버전.
6. 호출 한도 도달 시 미완료·100% 미만 진행률 유지.
7. 차트가 없는 로컬 모의 응답에서 TradingView 작업 실패 기록.
8. 차트·샘플과 실제 AI 보고서의 라이브러리 집계 구분.
9. 점검에서 시작한 프로세스와 임시 설치·데이터의 정리.

단독 EXE 검사에서는 외부 `team/` 폴더가 없는 상태에서 시작해 번들 안의 기본 문서
33개가 실행 파일 옆에 생성되는 것을 확인했습니다. 사용자 지침 편집 이력과 잠금
파일은 실행 파일 번들·ZIP에 포함하지 않습니다.
검증 결과는 빌드 작업 폴더의 `validation/source-v4-final.json`,
`validation/standalone-v4-final.json`, `validation/archive-v4-final.json`에 기록했습니다.
검증 문서를 반영한 실행 파일과 ZIP을 다시 생성하고 최종 설치 점검을 수행합니다.

이 절차는 실제 HTTP 설치 확인이지만 유료 AI를 호출하지 않으며 실제 TradingView

## API 키 보관과 재시작

AI 제공자별 API 키와 데이터 연결의 비밀값은 실행 중인 서버 메모리에만 보관합니다.
브라우저 저장소·분석 기록·배포 파일에는 저장하지 않습니다. 앱을 완전히 종료하거나
업데이트로 서버를 다시 실행하면 키를 다시 등록해야 합니다. 모델 목록 조회에만 입력한
키는 연결 확인 전까지 등록 상태로 바뀌지 않습니다. 연결 확인은 실제 모델 요청을 사용하며
계정 과금이 발생할 수 있습니다. 모델 목록에 표시된다고 실제 호출 권한까지 보장되지는 않습니다.
