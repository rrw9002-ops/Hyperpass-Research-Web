# 수업에서 따라 하는 실습

이 장은 **종목 찾기 → 차트 보기 → 팀에 질문 → 결과 저장** 순서로 진행합니다. 첫 수업은 1~3번까지 해도 하나의 연구 기록이 완성됩니다.

## 1. 스크리너에서 후보 찾기

1. **스크리너**에서 **국내 · KRW** 또는 **미국 · USD**를 선택하세요. 검색 결과 위에 표시된 제공자와 앱이 받은 시각을 확인합니다. **공급자에서 새로 조회**를 누르면 해당 공급자에 다시 요청합니다.
2. **국내**에서는 연결 상태에 따라 한국투자증권(KIS) 공개 마스터의 기준가 또는 KIS API 현재가가 표시됩니다. 키 연결 후 **이 페이지 KIS 상세 시세·PER 갱신**을 누르면 현재 보이는 종목만 개별 조회합니다. 전체 시장에서 PER를 검색할 때는 **항목별 출처와 제공 종목 수**를 먼저 보세요. **미제공 재무 지표 보강 · TradingView**는 원할 때만 켜고, 보강된 값은 별표로 구분합니다.
3. **미국**에서는 Yahoo Finance가 제공하는 최근 정규장 가격과 거래량을 봅니다. 표시할 열에서 **시세 시각**과 **표시 지연**을 켜세요. 장이 닫힌 동안 최신 관측값은 직전 거래일일 수 있습니다. 수신 시각과 실제 시세 시각을 함께 보세요.
4. 예를 들어 시장을 미국으로 바꾸고 **수익성 우수 → 검색하기**를 누릅니다. 이 조건에 ROE 관측값이 있는 종목만 남습니다. 거래소·업종·최솟값·최댓값을 바꿔 다시 검색해 보세요. **—**는 그 항목의 관측값이 비어 있다는 뜻입니다.
5. 종목 두 개에 체크하고 **선택 비교**를 누릅니다. 한 종목은 **차트**, 다시 보고 싶은 종목은 **관심 +**를 선택하세요. **CSV 다운로드**는 현재 필터·정렬에 맞는 결과 전체를 저장합니다.

## 2. SK하이닉스 차트를 확인하고 보관하기

1. **차트 연구실**에서 **차트 데이터 → Yahoo Finance**를 고르고 `SK하이닉스` 또는 `000660`을 입력합니다. 동명이 있으면 제안 목록에서 종목과 거래소를 확인해 고르세요.
2. 오른쪽 제목 **SK하이닉스 · 000660 / 일봉**과 출처·실제 봉 수를 확인합니다. 출처 또는 선택 종목을 바꾸면 새 자료를 불러오는 상태가 오른쪽에 나타납니다.
3. TradingView Desktop이 연결돼 있다면 **차트 데이터 → TradingView**로 바꿔 보세요. 어느 창을 사용할지 물으면 실습용 차트 탭을 고릅니다. 오른쪽에 TradingView가 표시되는지 확인하세요. 실패하면 오른쪽에 표시된 오류와 Desktop 연결 상태부터 봅니다.
4. 가격 위에서 단순이동평균·볼린저 밴드를 켜고 **보조지표**에서 RSI 또는 MACD를 골라 보세요. 자동으로 뜬 **미리보기**를 나중에 다시 보려면 **Second Brain에 저장**을 누릅니다.
5. 차트 아래에서 기술 분석 에이전트에 근거를 연결하면 표시된 봉과 계산 결과를 바탕으로 질문할 수 있습니다. 개인 추세선이나 지표 코드는 **차트 연구실 → 개인 지표·추세선**에서 만들고 저장합니다. Desktop 적용은 선택한 TradingView 차트에서 확인합니다.

## 3. 실제 AI 팀에 첫 질문 보내기

1. AI 서비스 하나를 연결한 뒤 **리서치 팀**을 엽니다. 처음에는 **종합 분석**을 두세요. 기술 분석가에게만 시작 질문을 보내려면 **누구에게 물어볼까요?**에서 기술 분석을 선택합니다. Head Manager의 검수와 필요한 독립 검토가 이어집니다.
2. **종목** 범주를 고르고 아래 질문을 입력합니다. 앞에서 저장한 차트를 근거로 연결하면 종목·기간이 명확해집니다.
```text
첨부한 SK하이닉스 일봉에서 최근 추세와 변동성을 설명해줘. 표시된 기간과 데이터 출처를 먼저 쓰고, 관측한 사실과 해석을 나눠줘. 판단을 바꾸게 할 조건 두 가지와 이 자료만으로 알 수 없는 점도 적어줘.
```
3. **이번 질문의 AI**에서 연결한 모델과 제공자가 지원하는 추론 강도를 고릅니다. 연결한 자료 출처, 공개 웹 조회 사용 여부, 호출 상한을 확인하고 **리서치 시작**을 한 번 누르세요.
4. 진행률, 현재 역할의 상태 표시, **진행 기록**을 봅니다. 퍼센트는 진행 단계의 추정치입니다. **최종 보고서가 완성됐습니다**와 **최종 보고서 저장**이 보이면 결과를 읽고 내려받을 수 있습니다. **미완료**라면 마지막 단계의 이유와 이미 수집한 근거를 먼저 확인하세요.
5. **역할별 근거**에서 누가 어떤 자료를 사용했는지 확인합니다. **Second Brain**에서 이후에 다시 열 수 있고, 분석한 종목은 **관심종목에 추가**로 보관할 수 있습니다.

## 4. 전략 백테스트 하나 끝내기

**백테스트**는 과거 자료의 모의 실행입니다. 아래 두 실습은 성과가 답하는 질문이 다릅니다.

1. **로그인 없이 포트폴리오 실습**을 하려면 검증 방식을 **포트폴리오**로 바꿉니다. 국내 또는 미국을 고르고 **PER 실습 불러오기**를 누르세요. 예제에는 공시일이 붙은 EPS와 두 종목이 들어 있습니다. 기간·시작금·보유 수·비용을 확인하고 **실행 조건 확인 → 백테스트 실행**을 누릅니다.
2. 결과에서 편입 종목, 미청산 포지션, 수수료, 슬리피지, 최대 낙폭(MDD), 벤치마크를 차례로 봅니다. MDD는 기간 중 자산이 앞선 고점에서 가장 크게 떨어진 비율입니다. 오늘의 재무 수치는 과거 PER 입력으로 사용할 수 없습니다. 내 자료를 쓸 때는 실제 공개일과 당시 EPS가 필요합니다.
3. **내 Pine 파일**을 사용하려면 **TradingView · Pine**을 선택합니다. 로그인한 Desktop 차트에 연결하고 **전략 파일 불러오기**로 `.pine` 파일을 열거나 `strategy()` 코드를 붙여넣습니다. 파일이 없으면 시작 코드 생성 도구로 예제를 만드세요. `indicator()`로 시작하는 개인 지표는 차트 연구실에서 사용합니다.
4. **단일 종목**으로 먼저 한 종목의 결과를 확인하세요. 이후 같은 화면에서 **종목 묶음** 또는 **시장 전체**를 고를 수 있습니다. 시장, 거래소·업종, 봉 주기와 코드에 지정한 기간·수수료·슬리피지를 확인한 뒤 실행하세요. 실행 중에는 선택한 Desktop 탭에서 다른 전략을 편집하지 않는 편이 좋습니다.
5. 완료된 종목의 실제 전략 보고서를 열어 체결 횟수, 기간, 비용과 손실 구간을 확인하고 **검증한 코드·조건을 내 전략에 저장**을 누릅니다. 종목별 실행에서는 각각 독립된 자본으로 성과가 계산됩니다. 여러 종목이 하나의 계좌를 공유하는 시뮬레이션에는 포트폴리오 방식을 사용하세요.

Pine은 해당 TradingView 계정의 로그인, 시세 이용 범위, 열린 차트와 전략 테스터 상태에 따라 제한될 수 있습니다. 앱은 실제 보고서를 받지 못한 종목의 사유를 기록합니다. 시장 전체 시뮬레이션은 조회 시점의 상장 목록을 사용하므로 과거 상장폐지 종목이 빠질 수 있습니다.

## 5. 다음 수업에 이어서 하기

- **Second Brain**에서 저장한 이름이나 종목을 검색하고 차트·보고서를 눌러 엽니다. 지도는 휠로 확대하고 밝은 점을 눌러 기록을 확인합니다.
- **백테스트 → 내 전략**에서 저장한 전략을 불러와 이름, 범위, 코드를 살펴봅니다. 수정한 전략은 새 이름으로 검증·저장하면 이전 결과와 비교하기 쉽습니다.
- 앱과 결과 파일은 내 컴퓨터에 있습니다. 다른 사람에게 결과를 보여주려면 보고서나 CSV를 내보내고, 공유할 범위에 개인 메모나 자료가 포함되는지 먼저 확인하세요.
