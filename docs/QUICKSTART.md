# 수강생 빠른 시작

처음에는 **앱 실행 → AI 한 곳 연결 → 제공 자료로 첫 분석** 순서로 진행하세요.
매매·계좌·주문 기능은 없는 연구용 앱입니다.

## 바로 해 보는 차트와 전략 실습

1. **차트 연구실**에서 `삼성전자`, `005930`, `애플`, `AAPL` 중 하나를 입력하고 조회하세요. 같은 이름에 여러 종목이 있으면 거래소를 확인해 선택하세요. 차트 위에서 국내 지수와 미국 지수도 바꿔 볼 수 있습니다.
2. **백테스트 연구실**에서 시장 전체, 직접 만든 종목 목록, 단일 종목 중 하나를 고르세요. 시장, 기간, 진입·청산 규칙, 초기 자금, 수수료, 슬리피지를 정하고 이름을 붙여 실행하세요. 결과에서 후보·포함·제외 종목 수와 실제 가상 체결 목록, 순수익률, MDD, 벤치마크를 함께 확인하세요.
3. **내 전략**에 저장하면 차트 연구실에서 같은 규칙을 다시 사용할 수 있습니다. 시장 전략의 종목 간 순위와 단일 종목 신호는 서로 다른 질문에 답하므로, 비교할 때는 사용한 엔진과 자금 배분을 확인하세요.
4. **TradingView Desktop**의 Pine 전략은 연구실의 TradingView 도구에서 실행하세요. **CSV 가져오기**에는 TradingView가 내보낸 실제 차트 파일이 필요합니다. Yahoo와 CSV 실습은 TradingView 연결 없이 시작할 수 있습니다.
5. 분석을 마친 보고서나 차트의 **관심종목에 추가**를 누르세요. **Second Brain → 내 관심종목**에서 최근 일봉 시세, 원래 보고서, 저장해 둔 차트 또는 현재 차트를 열 수 있습니다.

시장 검증은 조회 시점의 상장 목록을 사용합니다. 상장폐지 종목과 과거 편입 목록까지 복원한 결과로 해석하면 생존편향이 생깁니다. 시장 전체 실행 시간은 종목 수, 시세 제공자의 응답과 로컬 캐시에 따라 달라집니다.

## 1. 내 컴퓨터에 맞는 파일 받기

[다운로드 페이지](https://github.com/rrw9002-ops/Hyperpass-Research-Web/releases)의
배포 파일(Assets)에서 선택합니다.

| 컴퓨터 | 받을 ZIP |
| --- | --- |
| Windows | `Hyperpass-Research-Web-Windows.zip` |
| M1·M2·M3 등 M 시리즈 Mac | `Hyperpass-Research-Web-macOS-arm64.zip` |
| Intel Mac | `Hyperpass-Research-Web-macOS-x86_64.zip` |

Mac 종류는 **Apple 메뉴 → 이 Mac에 관하여**에서 확인합니다.
위 실행 파일 ZIP에는 Python이 포함됩니다. 별도의 **Source code ZIP**을 받으면
Python 3.11 이상이 필요하므로 처음에는 컴퓨터에 맞는 실행 파일 ZIP을 선택하세요.

## 2. 압축을 풀고 실행하기

ZIP을 **새 폴더에 모두 압축 해제**한 뒤 폴더 안의 파일을 엽니다.

- Windows: `Start-Windows.cmd` 또는 `Hyperpass-Research-Web.exe`
- Mac: `Start-Mac.command`

실행 창은 열어 두세요. 브라우저가 자동으로 열리지 않으면 실행 창에 표시된 주소를
브라우저에 입력합니다. 보통 `http://127.0.0.1:8765`이며 다른 포트가 표시될 수도 있습니다.
앱을 종료할 때는 실행 창에서 `Ctrl+C`를 누릅니다.

Mac 배포본에는 Apple 개발자 서명·공증이 없어 보안 경고로 실행이 차단될 수 있습니다.
차단되면 표시된 경고문을 강사에게 전달해 지원받으세요.

## 3. AI 한 곳만 연결하기

1. **API 연결하기** 또는 **AI 연결 관리**를 엽니다.
2. OpenAI·Claude·Gemini 중 사용할 서비스 **한 곳**을 선택하고 본인의 API 키를 입력합니다.
3. **모델 목록 불러오기**를 누르고 사용할 모델을 고릅니다. 모델 ID를 알고 있으면 직접 입력해도 됩니다.
4. **연결 확인 후 시작**을 누릅니다. **이번 질문의 AI**에는 연결할 때 고른 모델이 표시됩니다. 질문을 보내기 전에 모델과 추론 강도를 바꿀 수 있습니다.

실제 AI 분석에는 API 사용 권한과 이용 가능한 한도가 필요하며 연결 확인·분석에
API 요금이 발생할 수 있습니다. ChatGPT·Claude·Gemini 앱 구독은 API 인증과 별개입니다.
키는 앱을 완전히 종료하면 다시 입력해야 합니다.

OpenAI를 연결했다면 **이번 질문의 AI → 검증 설정 적용 · GPT-5.4 / medium**을
눌러 실제 분석 완료를 확인한 설정을 직접 적용할 수 있습니다. 해당 모델 접근 권한과
API 비용이 필요합니다. 버튼은 분석을 시작하지 않으며, 역할별 별도 설정은 유지합니다.
다른 AI나 모델도 직접 선택할 수 있습니다.

**KIS·FMP·Yahoo·OpenBB 같은 데이터 연결은 선택 사항**입니다. 아래 첫 연습은
직접 제공하는 자료를 사용하므로 데이터 키나 TradingView를 준비하지 않아도 됩니다.

## 4. 첫 분석 해보기

**리서치 팀**에서 다음처럼 설정합니다.

- 누구에게 물어볼까요?: **기본 분석 · 사업과 재무**
- 범주: **자유질문**
- AI 제공자·모델: OpenAI이면 위의 **검증 설정 적용** 버튼으로 선택하거나,
  본인이 연결한 AI·모델·지원 추론 강도를 직접 선택
- 웹 검색과 데이터 연결: 이번 연습에서는 선택하지 않음

**질문**에 붙여넣습니다.

```text
제공한 가상 기업 자료의 두 해를 비교해 주세요.
매출·영업이익의 변화와 이 자료만으로 판단할 수 없는 점을 정리해 주세요.
제공된 자료만 사용하고, 추가로 필요한 자료를 알려주세요.
```

**제공할 근거 · 자료**에 붙여넣습니다.

```text
학습용 가상 자료입니다. 실제 기업이나 시장 데이터가 아닙니다.
가상 기업 A, 단위: 억 원
2024년: 매출 100, 영업이익 10
2025년: 매출 120, 영업이익 12
주가, 현금흐름, 부채 자료는 제공되지 않았습니다.
```

**리서치 시작**을 누릅니다. 실제 API로 분석하되 입력 자료는 가상 사례인 연습입니다.
담당 에이전트를 하나 골라도 Head Manager의 근거 검수와 필요한 독립 검토가 이어집니다.
**화면 체험**은 API를 호출하지 않는 별도의 고정 샘플입니다.

## 5. 완료 확인하고 보고서 저장하기

진행 배너에서 현재 단계와 담당 역할을 확인합니다. 퍼센트는 단계 기준 추정치이며
보완·검토 중에는 같은 값에 머물 수 있습니다.
팀 카드의 주황색 불과 상태 문구는 지금 모델 응답을 기다리는 역할을 표시합니다.
여러 역할이 동시에 호출되면 해당 카드들이 함께 켜집니다.

**최종 보고서 완성 · 100%**가 표시되면 **통합 보고서**를 읽고 **보고서 저장**으로
Markdown 파일을 내려받습니다. **Second Brain**에서 저장한 기록을 다시 열 수 있습니다.
우주 지도의 빈 곳을 클릭하거나 휠을 굴려 확대하고, 확대한 지도를 드래그해 이동합니다.
기록 점을 클릭하면 해당 자료가 열립니다. 배율 숫자를 누르면 원래 위치로 돌아갑니다.

**중단·오류·호출 한도 도달**은 완료가 아닙니다. 표시된 원인과 진행 기록을 확인하세요.
도움이 필요하면 오류 문구와 멈춘 단계를 강사에게 보내고, API 키는 보내지 마세요.

## 6. 다음에 사용할 기능

**팀 지침 바꾸기:** **팀 구성**에서 문서를 선택해 수정하고 **변경 내용 저장**을
누릅니다. 공통 지침 1개·역할 지침 10개·분석 방법 10개·참고 문서 12개, 총 33개를
편집할 수 있습니다. 변경은 **다음에 시작하는 분석부터** 적용되며 진행 중인 분석은
시작 당시 지침을 유지합니다.

**실제 TradingView 백테스트:** 이 기능을 사용할 때만 TradingView Desktop을
설치하고 본인 계정으로 로그인해 차트를 엽니다. 웹앱의 **백테스트 → TradingView · Pine**에서 Desktop에 연결하고 검증할 종목·주기를 지정합니다. Pine 전략 코드를 넣어
**전략 적용 · 백테스트**를 실행합니다. TradingView API 키를 입력하는 방식은 아닙니다.
계정의 데이터·지표 개수·기능 제한은 그대로 적용됩니다.

**차트 연구실**에서 TradingView Desktop에 연결하고 종목 입력란에 `삼성전자`, `엔비디아` 또는 `NVDA`를 입력합니다. 목록에서 종목명과
거래소를 확인해 원하는 종목을 선택합니다. **Desktop 차트 설정 적용**으로 주기와 기본 지표를 반영합니다.

**차트 연구실**의 가격 차트에서 **개인 지표 · 추세선 ↓**를 누르세요. **차트에 무엇을 표시할까요?**에 `최근 1년간 고점들을 추세선으로 연결해줘`를 입력하고
**요청으로 코드 만들기**를 누릅니다. 코드를 확인한 뒤 선택한 TradingView Desktop 차트에 적용하세요. 적용 상태는 차트 연구실에서 확인합니다. 이 예제는 AI 키 없이 쓸 수 있습니다.
기본값은 최근 365일이며 각 고점은 오른쪽 5개 봉까지 마감한 뒤 확정합니다. 둘 이상의 고점이 있어야 선이 나타납니다.
다른 요청은 분석 화면에서 선택한 AI와 모델로 Pine 코드를 생성합니다. 직접 작성한
`indicator()` 코드도 넣을 수 있습니다. 코드를 검토한 뒤 **내 지표에 저장**하면 다시 열어 수정할 수 있습니다.

자세한 기능과 확인된 범위는 [전체 사용 안내](../README.md),
[차트 연구 안내](CHART-LAB.md), [검증 기록](VALIDATION.md)을 참고하세요.
