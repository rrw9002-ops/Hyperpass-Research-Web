Hyperpass 수강생 가이드

내 컴퓨터에서 첫 종목을 조회하고, AI 팀에 질문하고, 내 분석 방법으로 바꾸는 과정을 따라 해보세요.

내 컴퓨터에 설치하기

처음에는 압축 풀기 → 앱 열기 → 국내 또는 미국 종목 찾기까지만 해보세요. 여기까지는 AI 키 없이 할 수 있습니다. 에이전트에게 질문할 때 본인의 AI 서비스를 한 곳 연결합니다.

1. 내 컴퓨터에 맞는 ZIP 받기

수강생 다운로드 페이지를 엽니다. 아래 Assets를 펼쳐 다음 파일 중 하나를 클릭하세요. GitHub 로그인은 필요 없습니다.

  • Windows 64비트는 Hyperpass-Research-Web-Windows.zip을 받습니다. Windows 설정 → 시스템 → 정보에서 시스템 종류를 볼 수 있습니다. 이 배포판의 검증 대상은 x64입니다.
  • Mac은 왼쪽 위 사과 메뉴 → 이 Mac에 관하여를 엽니다. 칩에 Apple M1·M2·M3 등 M 시리즈가 보이면 Hyperpass-Research-Web-macOS-arm64.zip을 받습니다. 프로세서에 Intel이 보이면 Hyperpass-Research-Web-macOS-x86_64.zip을 받습니다.
  • 이름에 source가 들어간 ZIP은 앱 코드를 직접 바꾸는 실습용입니다. .sha256은 다운로드 확인용 파일입니다. 처음 실행할 때는 운영체제 이름이 들어간 ZIP을 고르세요.

2. 압축을 모두 풀고 실행하기

  1. Windows에서 다운로드 폴더를 열고 받은 ZIP을 마우스 오른쪽 버튼으로 클릭한 뒤 모두 압축 풀기를 누릅니다. 압축이 풀린 폴더 안으로 들어가 Start-Windows.cmd를 두 번 클릭하세요. 확장자를 숨긴 환경에서는 Start-Windows로 보일 수 있습니다.
  2. Mac에서는 Finder → 다운로드에서 ZIP을 두 번 클릭합니다. 생긴 폴더를 열고 Start-Mac.command를 두 번 클릭하세요.
  3. 실행 창이 열리고 브라우저에 HYPERPASS 화면이 표시됩니다. 브라우저가 자동으로 열리지 않으면 실행 창에 나온 http://127.0.0.1:숫자 주소 전체를 복사해 브라우저 주소창에 붙여넣으세요. 포트 번호는 컴퓨터마다 다를 수 있습니다.
  4. 위쪽에 리서치 팀 · 차트 연구실 · 스크리너 · 백테스트가 보이면 설치가 끝났습니다. 오른쪽 위 수강생 가이드로 이 문서를 다시 열 수 있습니다. 앱을 켜지 않고 읽으려면 압축을 푼 폴더의 수강생-시작가이드.html을 여세요.

실행 창은 사용하는 동안 열어 두세요. 마칠 때는 그 창에서 Ctrl+C를 누릅니다. 다음 수업에는 같은 폴더에서 같은 시작 파일을 실행하세요. Windows·Mac 실행용 ZIP에는 Python 실행 환경이 포함되어 있습니다.

3. 연결 없이 첫 화면 확인하기

  1. 스크리너 → 국내를 선택하고 한국투자증권 KIS와 수신 시각을 확인합니다. 키를 연결하기 전에는 KIS가 공개한 종목 파일의 기준가가 표시됩니다.
  2. 검색 칸에 005930을 입력하고 검색하기를 누릅니다. 삼성전자 · 005930 행이 보이면 종목을 찾은 것입니다.
  3. 같은 행의 차트를 누릅니다. 인터넷 연결 상태에서 Yahoo 가격 이력이 들어오면 삼성전자 · 005930 / 일봉과 실제 출처·봉 개수가 표시됩니다.
  4. AI 화면도 둘러보려면 리서치 팀 → 화면 체험을 누릅니다. 체험은 정해진 예시로 화면 사용법을 보여줍니다. 본인의 실제 보고서는 다음 장에서 AI를 연결한 뒤 만듭니다.

설치가 멈췄을 때

  • ZIP 안에 파일이 많은데 무엇을 누를지 모르겠어요. 다운로드 폴더에 있는 원래 ZIP을 닫고 압축을 푼 새 폴더로 이동하세요. 윈도우는 Start-Windows.cmd, 맥은 Start-Mac.command입니다.
  • 주소가 열리지 않아요. 앱 실행 창이 열려 있는지 확인하고 그 창에 표시된 주소를 다시 사용하세요. 강사 화면의 포트 번호를 복사하면 다른 주소로 갈 수 있습니다.
  • Mac 또는 Windows가 실행자를 확인할 수 없다고 해요. 강사가 안내한 공개 릴리스에서 운영체제에 맞는 파일을 받았는지 먼저 확인하세요. 배포본의 서명·공증 상태에 따라 경고가 표시될 수 있습니다. 회사나 학교 컴퓨터라면 표시된 경고 문구와 OS 종류를 담당자에게 전달하세요. Apple의 Mac 앱 실행 안내
  • 이 창을 닫아 버렸어요. 압축을 푼 폴더에서 시작 파일을 다시 여세요. 앱을 완전히 다시 시작하면 필요한 API 키를 다시 연결합니다.

처음부터 AI와 같이 설치하기

Codex나 평소 쓰는 AI의 새 대화창에서 아래 문장을 붙여넣으세요. 대괄호 안에는 본인 상황을 적습니다. AI가 화면을 직접 볼 수 없는 환경이면 지금 보이는 버튼 이름이나 경고 문구만 함께 보내세요.

AI에게 보낼 질문
나는 프로그램 설치가 처음인 수강생입니다. 컴퓨터는 [Windows 11 / Mac M 시리즈 / Intel Mac]이고, 강사가 준 Hyperpass 배포 파일을 받으려고 합니다. 지금 화면에는 [Assets가 보임 / 파일을 내려받음 / 압축을 품]이 표시됩니다. 이 가이드의 설치 부분을 기준으로, 지금 할 한 단계와 성공했을 때 보일 화면만 알려 주세요. 내가 결과를 답하면 다음 단계로 넘어가 주세요.

데이터와 AI 연결하기

처음에는 키 없이 차트 연구실에서 삼성전자 또는 AAPL을 조회할 수 있습니다. 국내 현재가를 직접 받을 때는 KIS를, 에이전트가 보고서를 작성할 때는 AI 서비스를 한 곳 연결하세요.

국내 스크리너에 한국투자증권 KIS 연결하기

스크리너 → 국내에는 한국투자증권의 코스피·코스닥 종목 마스터가 들어옵니다. 공식 파일의 기준가, 전일 거래량, 전일 기준 시가총액, 재무 기준일을 확인할 수 있습니다. 기준가는 권리락 등에 따라 직전 종가와 차이가 날 수 있습니다. 장중 현재가와 누적 거래대금을 받으려면 KIS를 연결하세요. KIS 종목정보파일

  1. KIS Developers의 API 신청에서 본인 계좌의 실전투자 Open API 서비스를 신청하고 발급된 App Key와 App Secret을 준비합니다. 가입·서비스 신청은 본인의 한국투자증권 계정에서 진행하세요. KIS Developers · 한국투자증권 공식 연동 예제
  2. 앱 상단 데이터 연결 → 한국투자증권 KIS를 엽니다. App Key와 App Secret을 각각 입력하고 검사 / 수집 종목 코드에 005930을 입력합니다. 이 앱의 입력 항목은 두 키와 조회할 종목 코드입니다.
  3. 실제 조회로 연결 확인을 누릅니다. 실제 조회 성공 또는 조회 확인됨이 표시되면 삼성전자 시세를 읽은 것입니다.
  4. 스크리너 → 국내에서 시세를 갱신합니다. KIS API는 여러 종목을 나누어 호출합니다. 수집 상태가 완료되면 현재가와 누적 거래대금을 확인하세요. 수신 시각은 앱이 응답을 받은 시각이고, 재무 지표의 기준일은 별도입니다. 이 페이지 KIS 상세 시세·PER 갱신을 누르면 현재 페이지의 종목에 KIS가 제공하는 PER·PBR도 조회합니다. 이후 PER 조건으로 검색할 때는 항목별 출처와 제공 종목 수에서 몇 종목에 값이 있는지 확인하세요.
  5. API 키를 등록하지 않은 상태에서는 마스터의 기준가가 표시됩니다. 마스터와 복수종목 시세 API가 제공하지 않는 PER·PBR 등에는 빈칸이 생길 수 있습니다. 키 등록 전에도 국내 전 종목에 PER 등 조건을 적용해 보려면 미제공 재무 지표 보강 · TradingView를 선택해 조회합니다. 실제로 값이 제공된 종목만 해당 조건을 통과하며, 보강한 항목은 TradingView 출처로 표시됩니다.

인증 오류가 나면 실전용 키 쌍이 맞는지, 두 입력란이 뒤바뀌지 않았는지 확인합니다. 호출 제한이 표시되면 현재 수집이 끝난 뒤 잠시 기다려 다시 조회하세요. KIS 복수종목 시세 명세 · KIS 현재가 명세

미국 스크리너에서 Yahoo Finance 사용하기

  1. 스크리너 → 미국을 고릅니다. Yahoo Finance 공개 데이터는 별도 키 없이 조회합니다.
  2. 시세 수집이 끝나면 AAPL을 검색해 종목 이름, 티커, 통화, 출처를 확인합니다. 결과 표의 기준 시각과 갱신 상태를 확인한 다음 필터를 적용하세요.
  3. 차트만 보고 싶다면 차트 연구실 → Yahoo Finance에서 종목·기간·봉 주기를 고릅니다. 국내 종목은 삼성전자, 005930, 미국 종목은 애플, AAPL처럼 입력합니다. 동명이거나 여러 거래소에서 거래되는 종목은 검색 결과의 코드를 확인하세요.

휴장·주말에는 직전 거래 세션 자료일 수 있습니다. Yahoo는 거래소·상품에 따라 지연 자료를 제공하며 공개 데이터 연결을 일시적으로 제한할 수 있습니다. 조회 시간이 갱신돼도 가격의 거래일은 그대로일 수 있습니다. Yahoo 거래소별 데이터 및 지연 안내

TradingView 차트와 CSV 연결하기

  1. Windows 또는 Mac에 TradingView Desktop을 설치하세요. 앱 차트를 불러오는 데 TradingView API 키는 필요 없습니다. TradingView Desktop 공식 다운로드
  2. Hyperpass에서 차트 연구실 → 차트 데이터 → TradingView · Desktop 차트 조회를 선택하세요. 오른쪽에 TradingView Desktop 연결하기가 보이면 Desktop 연결 실행을 누릅니다. 일반 모드로 실행 중이어서 연결되지 않으면 TradingView에서 작업을 저장하고 앱을 완전히 종료한 뒤 이 버튼을 다시 누르세요. 기본 연결 포트는 9222입니다.
  3. TradingView Desktop에서 종목 차트 하나를 엽니다. 로그인을 요청하면 본인 계정으로 로그인하세요. Hyperpass가 잠시 동안 열린 차트를 자동 확인합니다. 나중에 차트를 열었으면 연결 확인 · 차트 조회를 누릅니다. 사용할 탭을 선택하라는 안내가 보이면 오른쪽에서 실습에 쓸 탭을 고르세요. 그 탭의 종목·주기가 변경됩니다.
  4. Hyperpass 종목 입력란에 SK하이닉스 또는 000660을 입력하세요. 오른쪽 제목에 SK하이닉스 · 000660, 출처에 TradingView Desktop과 봉 개수가 보이면 연결에 성공한 것입니다. 상단 차트 조회로 직접 다시 불러올 수 있습니다. KRX 지연 피드를 받으면 지연 시세로 표시됩니다. 이전 버전에서 저장한 Desktop 차트의 종목과 가격이 의심되면 같은 종목·주기를 새로 조회해 날짜별 가격을 대조하세요. 남기고 싶은 차트만 이 차트를 Second Brain에 저장을 누르세요.
  5. 조회되는 기간은 Desktop이 해당 차트에 로드한 봉 수에 따라 달라지며 최대 500봉입니다. 원하는 봉 주기를 지정할 때는 조회·지표에 사용할 Desktop 주기를 사용합니다. 기존 Yahoo 차트의 조회 기간을 늘려도 Desktop의 봉 수가 늘지는 않습니다.
  6. TradingView에서 내보낸 파일로 연습하려면 차트 데이터에서 TradingView · CSV 가져오기를 선택해 해당 종목의 CSV를 넣습니다. CSV의 통화·봉 주기를 실제 파일과 맞추고 조회합니다. CSV는 내보낸 시점의 자료를 재현합니다. TradingView 차트 데이터 내보내기

Desktop 연결 실패가 표시되면 이 PC에서 Desktop이 실행 중인지, 차트 탭이 열려 있는지, 포트가 일치하는지 확인하세요. TradingView에서 열기는 선택한 종목을 외부 웹 차트로 여는 링크입니다. 앱 안에서 Desktop 시세를 읽으려면 위 연결 단계가 필요합니다.

AI 한 곳을 등록하고 리서치 시작하기

  1. 리서치 팀 → API 연결하기 또는 화면 상단의 AI 연결 메뉴를 엽니다. OpenAI, Claude, Gemini 중 사용할 서비스 한 곳을 선택합니다.
  2. 해당 서비스의 개발자 계정에서 본인 프로젝트용 API 키를 발급합니다. OpenAI는 API 대시보드, Claude는 Claude Console, Gemini는 Google AI Studio에서 발급합니다. 웹 채팅 로그인·구독과 개발자 API의 사용 권한·한도·결제 설정은 따로 관리됩니다. OpenAI API 시작 안내 · Claude API 키 발급 · Gemini API 키 설정
  3. 키를 앱의 API 키 칸에 붙여넣고 모델 목록 불러오기를 누릅니다. 본인 프로젝트에 표시되는 모델을 선택하거나 사용할 수 있는 모델 ID를 입력합니다. 연결 확인 후 시작을 누르면 선택한 키와 모델로 소량의 실제 요청을 보냅니다.
  4. 이번 질문의 AI에서 연결한 서비스와 모델을 확인합니다. 질문별로 모델과 지원되는 추론 강도를 고를 수 있습니다. 목록에 원하는 강도가 없으면 모델 기본값으로 시작하세요.
  5. 누구에게 물어볼까요?에서 종합 분석 또는 특정 에이전트를 고르고 질문을 입력합니다. 예를 들어 첨부 차트에 나타난 가격 추세와 이 자료만으로 판단하기 어려운 점을 정리해 주세요.라고 요청할 수 있습니다. 개인 차트를 분석하려면 먼저 차트 연구실에서 조회한 차트를 분석에 연결하세요. 리서치 시작을 누르고 단계별 진행 상태를 확인합니다.
  6. 완료되면 최종 보고서가 완성됐습니다와 최종 보고서 탭이 표시됩니다. 이전 결과는 Second Brain에서 다시 엽니다.

연결이 안 되면 선택한 서비스의 키가 맞는지, 모델 사용 권한이 있는지, 프로젝트의 API 사용 한도와 잔액이 충분한지 확인하세요. 응답 속도 제한은 잠시 기다렸다 재시도합니다. 키는 실행 중인 로컬 서버의 메모리에 보관되므로 앱을 완전히 종료했다면 다시 입력하세요. 문의할 때는 오류 문구와 서비스·모델 이름만 공유하고 키 입력란은 가리세요.

FMP와 OpenBB를 추가로 쓰는 경우

  • FMP를 사용하려면 Financial Modeling Prep 개발자 대시보드에서 키를 발급하고 데이터 연결 → FMP에 입력하세요. 검사 종목에 AAPL을 넣고 실제 조회로 연결 확인을 누릅니다. 요금제별로 열 수 있는 엔드포인트와 호출 한도가 다릅니다. FMP API 시작 안내
  • OpenBB를 쓰는 수강생은 자신의 PC에 필요한 OpenBB REST API와 데이터 제공자 확장을 설치하고 openbb-api를 실행합니다. 터미널에 표시된 포트와 설치한 API 버전을 데이터 연결 → OpenBB에 입력하세요. 기본 포트는 6900입니다. 앱은 v5의 Cboe 시세 또는 v4의 yfinance 가격 이력을 조회합니다. 설치된 서버에 사용하는 경로와 제공자가 있어야 합니다. 서버 인증을 켰다면 해당 서버의 사용자명·비밀번호를 함께 입력한 뒤 AAPL로 연결을 확인하세요. OpenBB REST API 시작 안내

수업에서 따라 하는 실습

이 장은 종목 찾기 → 차트 보기 → 팀에 질문 → 결과 저장 순서로 진행합니다. 첫 수업은 1~3번까지 해도 하나의 연구 기록이 완성됩니다.

1. 스크리너에서 후보 찾기

  1. 스크리너에서 국내 · KRW 또는 미국 · USD를 선택하세요. 검색 결과 위에 표시된 제공자와 앱이 받은 시각을 확인합니다. 공급자에서 새로 조회를 누르면 해당 공급자에 다시 요청합니다.
  2. 국내에서는 연결 상태에 따라 한국투자증권(KIS) 공개 마스터의 기준가 또는 KIS API 현재가가 표시됩니다. 키 연결 후 이 페이지 KIS 상세 시세·PER 갱신을 누르면 현재 보이는 종목만 개별 조회합니다. 전체 시장에서 PER를 검색할 때는 항목별 출처와 제공 종목 수를 먼저 보세요. 미제공 재무 지표 보강 · TradingView는 원할 때만 켜고, 보강된 값은 별표로 구분합니다.
  3. 미국에서는 Yahoo Finance가 제공하는 최근 정규장 가격과 거래량을 봅니다. 표시할 열에서 시세 시각과 표시 지연을 켜세요. 장이 닫힌 동안 최신 관측값은 직전 거래일일 수 있습니다. 수신 시각과 실제 시세 시각을 함께 보세요.
  4. 예를 들어 시장을 미국으로 바꾸고 수익성 우수 → 검색하기를 누릅니다. 이 조건에 ROE 관측값이 있는 종목만 남습니다. 거래소·업종·최솟값·최댓값을 바꿔 다시 검색해 보세요. —는 그 항목의 관측값이 비어 있다는 뜻입니다.
  5. 종목 두 개에 체크하고 선택 비교를 누릅니다. 한 종목은 차트, 다시 보고 싶은 종목은 관심 +를 선택하세요. CSV 다운로드는 현재 필터·정렬에 맞는 결과 전체를 저장합니다.

2. SK하이닉스 차트를 확인하고 보관하기

  1. 차트 연구실에서 차트 데이터 → Yahoo Finance를 고르고 SK하이닉스 또는 000660을 입력합니다. 동명이 있으면 제안 목록에서 종목과 거래소를 확인해 고르세요.
  2. 오른쪽 제목 SK하이닉스 · 000660 / 일봉과 출처·실제 봉 수를 확인합니다. 직접 다시 조회하려면 종목 입력칸 바로 아래 차트 조회를 누르세요. 출처 또는 선택 종목을 바꾸면 새 자료를 불러오는 상태가 오른쪽에 나타납니다.
  3. TradingView Desktop이 연결돼 있다면 차트 데이터 → TradingView로 바꿔 보세요. 어느 창을 사용할지 물으면 실습용 차트 탭을 고릅니다. 오른쪽에 TradingView가 표시되는지 확인하세요. 실패하면 오른쪽에 표시된 오류와 Desktop 연결 상태부터 봅니다.
  4. 가격 위에서 단순이동평균·볼린저 밴드를 켜고 보조지표에서 RSI 또는 MACD를 골라 보세요. 자동으로 뜬 미리보기를 나중에 다시 보려면 Second Brain에 저장을 누릅니다.
  5. 차트 아래에서 기술 분석 에이전트에 근거를 연결하면 표시된 봉과 계산 결과를 바탕으로 질문할 수 있습니다. 고점 추세선은 개인 지표·추세선 → 1년 고점 추세선 예시 → 현재 종목 차트에 표시로 그립니다. 원래 보고 있던 종목의 캔들 위에 선과 고점 개수가 표시됩니다. 종목 차트 위의 고점에 마우스를 올리면 고점일과 확정일을 구분해 읽을 수 있습니다. 저장한 코드도 같은 방식으로 적용합니다. 개인 지표는 화면에서 확인하고, 코드 보관은 내 지표에 저장을 누르세요. 이 선은 현재 기술 분석가에게 전달하는 저장 차트에는 포함되지 않습니다.
  6. 종목 위의 시장 지수에서 국내 → 코스피 또는 미국 → S&P 500을 선택하세요. 일봉 위에 마우스를 올리면 그날의 가격과 아래쪽의 ATR(14)을 함께 볼 수 있습니다. ATR의 단위는 지수 포인트입니다. 종가만 제공될 때는 화면에 이유가 표시됩니다.

4. 전략 백테스트 하나 끝내기

백테스트는 과거 자료의 모의 실행입니다. 아래 두 실습은 성과가 답하는 질문이 다릅니다.

  1. 로그인 없이 포트폴리오 실습을 하려면 검증 방식을 포트폴리오로 바꿉니다. 국내 또는 미국을 고르고 PER 실습 불러오기를 누르세요. 예제에는 공시일이 붙은 EPS와 두 종목이 들어 있습니다. 기간·시작금·보유 수·비용을 확인하고 실행 조건 확인 → 백테스트 실행을 누릅니다.
  2. 결과에서 편입 종목, 미청산 포지션, 수수료, 슬리피지, 최대 낙폭(MDD), 벤치마크를 차례로 봅니다. MDD는 기간 중 자산이 앞선 고점에서 가장 크게 떨어진 비율입니다. 오늘의 재무 수치는 과거 PER 입력으로 사용할 수 없습니다. 내 자료를 쓸 때는 실제 공개일과 당시 EPS가 필요합니다.
  3. 내 Pine 파일을 사용하려면 TradingView · Pine을 선택합니다. 로그인한 Desktop 차트에 연결하고 전략 파일 불러오기로 .pine 파일을 열거나 strategy() 코드를 붙여넣습니다. 파일이 없으면 시작 코드 생성 도구로 예제를 만드세요. indicator()로 시작하는 개인 지표는 차트 연구실에서 사용합니다.
  4. 단일 종목으로 먼저 한 종목의 결과를 확인하세요. 이후 같은 화면에서 종목 묶음 또는 시장 전체를 고를 수 있습니다. 시장, 거래소·업종, 봉 주기와 코드에 지정한 기간·수수료·슬리피지를 확인한 뒤 실행하세요. 실행 중에는 선택한 Desktop 탭에서 다른 전략을 편집하지 않는 편이 좋습니다.
  5. 완료된 종목의 실제 전략 보고서를 열어 체결 횟수, 기간, 비용과 손실 구간을 확인하고 검증한 코드·조건을 내 전략에 저장을 누릅니다. 종목별 실행에서는 각각 독립된 자본으로 성과가 계산됩니다. 여러 종목이 하나의 계좌를 공유하는 시뮬레이션에는 포트폴리오 방식을 사용하세요.

Pine은 해당 TradingView 계정의 로그인, 시세 이용 범위, 열린 차트와 전략 테스터 상태에 따라 제한될 수 있습니다. 앱은 실제 보고서를 받지 못한 종목의 사유를 기록합니다. 시장 전체 시뮬레이션은 조회 시점의 상장 목록을 사용하므로 과거 상장폐지 종목이 빠질 수 있습니다.

5. 다음 수업에 이어서 하기

  • Second Brain에서 저장한 이름이나 종목을 검색하고 차트·보고서를 눌러 엽니다. 지도는 휠로 확대하고 밝은 점을 눌러 기록을 확인합니다.
  • 백테스트 → 내 전략에서 저장한 전략을 불러와 이름, 범위, 코드를 살펴봅니다. 수정한 전략은 새 이름으로 검증·저장하면 이전 결과와 비교하기 쉽습니다.
  • 앱과 결과 파일은 내 컴퓨터에 있습니다. 다른 사람에게 결과를 보여주려면 보고서나 CSV를 내보내고, 공유할 범위에 개인 메모나 자료가 포함되는지 먼저 확인하세요.

역할 지침은 담당자가 어떤 질문에 답하고 무엇을 넘겨줄지 정합니다. 분석 방법은 근거를 살펴볼 순서와 결과의 형식을 정합니다. 예를 들어 기술 분석가에게 매번 데이터 출처와 기준일을 표시하게 해 보세요.

  3. 리서치 팀에서 새 질문을 시작하고 담당자에 기술 분석을 고릅니다. 저장된 차트를 근거로 연결한 뒤 “이 차트의 최근 추세와 해석이 달라지는 조건을 설명해 줘”라고 요청합니다.
